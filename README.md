# Neokirk (Neo-Order-project)

Eitcha! Bem-vindo ao **Neokirk** — o resenha de gerenciamento de restaurante 67. Bora Bill!

Sistema completo de gerenciamento de pedidos de restaurante, com cardápio digital,
área do cliente (mesa), painel do atendente e módulo gerencial — tche tcheee!

## Como rodar a resenha

O código-fonte principal fica na pasta `jules_session_1378551908417141757/`:

- Abra o `index.html` no navegador e a resenha começa (não precisa de build).
- Pra rodar os testes: `node tests/store.test.js`
